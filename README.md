# Aria — AI Companion (Godot 4 + Local LLM + Voice + Node Automation)

Локальный 3D ИИ-компаньон на базе **Godot 4**, работающий полностью офлайн на Linux:
- **LLM:** Локальные модели GGUF через `NobodyWho` (`Qwen`, `LFM3`).
- **TTS:** Двойной синтез речи — `Piper TTS` и `Kyutai Pocket-TTS`.
- **STT:** Голосовой ввод и режим живого звонка через `Faster-Whisper` (`PipeWire` / `parecord`).
- **Node Editor:** Визуальное программирование сценариев терминала `zsh` на базе `GraphEdit`.
- **UI:** Прозрачный оверлей рабочего стола и тема матового стекла (GLSL Blur + Linux Compositor Blur).
