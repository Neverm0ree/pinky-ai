# Pinky AI — AI Companion (Godot 4 + Local LLM + Voice + Node Automation)

Локальный 3D ИИ-компаньон на базе **Godot 4**, работающий полностью офлайн на Linux:
- **LLM:** Local GGUF models `NobodyWho` (`Qwen`, `LFM3`).
- **TTS:** Support TTS — `Piper TTS` и `Kyutai Pocket-TTS`.
- **STT:**  `Faster-Whisper` (`PipeWire` / `parecord`).
- **Node Editor:** Visual node programming `cmd` `GraphEdit`.
